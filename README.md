# Tedd.ReadOnlyStructGenerator
.NET Source Generator for duplicating structs to read-only copies.

## Architecture

The project operates strictly as a Roslyn compile-time source generator pipeline. It evaluates syntax trees during compilation to deterministically emit `readonly` structurally identical copies of designated value types.

**Hypothetical Enhancements:** Please note that runtime components such as hierarchical data binding and routed event infrastructures are strictly hypotheses for planned future enhancements and are not currently established framework capabilities.

## Usage

By default, the `[GenerateReadOnlyStruct]` attribute does not generate a constructor or a copy constructor.

Adding `[GenerateReadOnlyStruct(true, true)]` to a struct like this:

```csharp
namespace Example;

[GenerateReadOnlyStruct(true, true)]
public struct Test
{
    public float X;
    public float Y;
    public float Z;
}
```

will inject this code into your project:

```csharp
#define RO_GEN

// This file was generated by Tedd.StructCopyGenerator
namespace Example
{
    [GenerateReadOnlyStruct(true, true)]
    public readonly struct ReadOnlyTest
    {
        public readonly float X;
        public readonly float Y;
        public readonly float Z;
        public ReadOnlyTest(Test value)
        {
            X = value.X;
            Y = value.Y;
            Z = value.Z;
        }

        public ReadOnlyTest(float x, float y, float z)
        {
            this.X = x;
            this.Y = y;
            this.Z = z;
        }
    }
}
```

`[GenerateReadOnlyStruct]` takes two optional boolean parameters which default to `false`:

* GenerateConstructor
* GenerateCopyConstructor

This allows you to prevent constructors from being generated in case you prefer manual implementation or do not require them. Any existing constructors in your struct will automatically be ported and renamed to match the generated `ReadOnly` struct.

```csharp
namespace Example;

[GenerateReadOnlyStruct(false, false)] // Or just [GenerateReadOnlyStruct]
public struct Test2
{
    public float X;
    public float Y;
    public float Z;

    public Test2(float x, float y, float z)
    {
        this.X = x;
        this.Y = y;
        this.Z = z;
    }
}
```

will inject this code into your project:

```csharp
#define RO_GEN

// This file was generated by Tedd.StructCopyGenerator
namespace Example
{
    [GenerateReadOnlyStruct(false, false)]
    public readonly struct ReadOnlyTest2
    {
        public readonly float X;
        public readonly float Y;
        public readonly float Z;
        public ReadOnlyTest2(float x, float y, float z)
        {
            this.X = x;
            this.Y = y;
            this.Z = z;
        }
    }
}
```

The constant `RO_GEN` is defined for every copy. It can be used for customizing code.

```csharp
namespace Example;

using System.Numerics;

[GenerateReadOnlyStruct]
public struct Test3
{
    public float X;
    public float Y;
    public float Z;

    public Test3(float x, float y, float z)
    {
        this.X = x;
        this.Y = y;
        this.Z = z;
    }
    
    public Vector3 Vector3 {
        get => new Vector3(X, Y, Z);
#if !RO_GEN
        // This section is only applicable for the mutable version of this struct
        set {
            X = value.X;
            Y = value.Y;
            Z = value.Z;
        }
#endif
    }
}
```

will essentially inject this code into your project. Note that preprocessor directives such as `#if !RO_GEN` are retained in the generated code, but since `#define RO_GEN` is added to the top of the file, the enclosed code is excluded from compilation.

```csharp
#define RO_GEN

// This file was generated by Tedd.StructCopyGenerator
namespace Example
{
    using System.Numerics;

    [GenerateReadOnlyStruct]
    public readonly struct ReadOnlyTest3
    {
        public readonly float X;
        public readonly float Y;
        public readonly float Z;
        public ReadOnlyTest3(float x, float y, float z)
        {
            this.X = x;
            this.Y = y;
            this.Z = z;
        }

        public Vector3 Vector3
        {
            get => new Vector3(X, Y, Z);
#if !RO_GEN
            // This section is only applicable for the mutable version of this struct
            set {
                X = value.X;
                Y = value.Y;
                Z = value.Z;
            }
#endif
        }
    }
}
```
